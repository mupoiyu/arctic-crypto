# Arctic Crypto

> Cold storage wallet with ice-themed UI

## Features

- Multi-wallet
- Transaction history
- Price alerts
- Security vault

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Blockchain: Solidity, Rust, Web3.js
- AI: MiMo V2 Flash, Claude Code

## Installation

```bash
git clone https://github.com/mupoiyu/arctic-crypto.git
cd arctic-crypto
npm install
npm run dev
```
